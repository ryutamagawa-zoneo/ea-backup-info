# EA Backup

EA Backup is a personal backup configuration operated by its owner. It uses rclone on the owner's computer to copy selected local development files to the owner's Google Drive. It is not a service offered to other users.

The application requests the Google Drive `drive.file` scope to create backup files and to read or update files authorized for this application. Reading those files supports backup checks and restoration. Replaced files can be retained as previous versions. This backup configuration does not automatically delete destination-only files.

Google account authorization is requested separately. This website does not sign users in or receive backup data or OAuth credentials.
