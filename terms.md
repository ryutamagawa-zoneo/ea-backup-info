# EA Backup terms of use

EA Backup is a personal configuration for the operator's own backup tasks. It is not a public backup service, and this website does not create an account, subscription, or storage service for visitors.

The operator is responsible for choosing backup sources, managing storage capacity, controlling access, reviewing transfer results, and checking restorations. A successful transfer does not establish that every application or file can be used on another operating system.

The configuration uses rclone and Google Drive. Those products remain subject to their respective licenses and applicable service terms. This documentation does not modify those terms or promise uninterrupted service or guaranteed recovery.
